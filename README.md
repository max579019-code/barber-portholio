# Barber Portfolio Template

Учебный адаптивный шаблон сайта персонального барбера.

## Что реализовано

- Главная страница и раздел «Работы»
- Адаптивный дизайн для телефона и компьютера
- Мобильное меню
- Галерея работ
- Блок о барбере
- Демонстрационные отзывы
- Форма выбора даты и времени
- Проверка имени и номера телефона
- Демонстрационное сообщение после отправки формы
- Кликабельный номер телефона

## Технологии

- HTML
- CSS
- JavaScript

## Важно

Форма записи демонстрационная: данные не сохраняются и никуда не отправляются.

Все данные шаблона находятся в объекте `barber` внутри файла `index.html`.
Перед использованием для реального клиента нужно заменить учебные тексты, отзывы, изображения, телефон и настроить реальный способ получения заявок.
